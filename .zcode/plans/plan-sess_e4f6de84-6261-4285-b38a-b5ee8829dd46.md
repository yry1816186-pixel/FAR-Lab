# FAR-Lab 彻底升级总计划（四波 15 批 + 常设协议，指令 §1-26 全覆盖）

现有 Human Experience 视为失败基线，可推翻。同时守住宪法底线：显示↔真实能力一一映射、无假进度、无 design theater、Node 产物零新运行时依赖（web 前端依赖另论）、secrets 不进 UI、科学断言需证据。

## 常设协议（贯穿全程，每批必做）
- **R1 三视角批判**：Product/HCI/Scientific 独立攻击每批结果，P0/P1 必修后复验。
- **R2 dogfood 度量台账**：每批真实任务记录 Steps/Time/Latency/Confusion/Context Switches，与基线（B1 建立）量化对比，落 evidence/W-PEX/。
- **R3 CPP 滚动清单**：3-7 个最高价值产品问题持续维护，P0/P1 未清不做 P3 打磨。
- **R4 定向研究**：每批设计前做精准竞品/HCI 研究（结论直接改实现，不留报告文档）。
- **R5 状态落盘**：.planning/.control 每批更新，跨会话断点续作。

## Wave 1 — 根基（基线审判 + 骨架 + 数据密度）

**B0 状态对账**：EXECUTION_STATE 补 S2/S3 DONE 证据；散落 yml 移 evidence/W-PEX/；总纲落盘 PLAN-product-experience.md；提交推送。

**B1 全程审判基线（指令 §2 正式化）**：以首次使用的科研者身份完整走通 Idea→输入→问题→文献→反证→假设→比较质疑→证伪→计划→实验→结果→修订→版本→导出全程；逐点记录迷惑/后台感/工程细节暴露/信息过载或不足/跳转/响应慢/层级错误/思维断续；产出摩擦清单 + CPP v2 重排 + 各表面设计方向（timebox，结论全部喂给后续批）。

**B2 工作台骨架重构**：①IA 按任务心智重排——科学面一级（问题/证据/假设/计划/实验/修订链），工程面渐进披露（events/receipts/元数据→「技术细节」检查器），run ID 全面退居次级；②Command palette（Ctrl/Cmd+K 自研零依赖）：动作 + 全局搜索（按问题搜 run、按陈述搜假设、按文本搜 claim，新增 `GET /api/v1/search?q=` SQL LIKE 零依赖）；③quick capture：`n`/`#new`/全局捕获条/首访 onboarding 空态引导；④视觉层级升级：密度/留白/typography scale/motion tokens 重校，科学语义组件语言统一（Evidence/Counter/Claim/Conflict/Unknown/Hypothesis/Uncertainty/Falsification/Version 一套视觉语法）；⑤键盘流（n、/、Cmd+K、←→、Esc）+ 响应式审计。

**B3 等待期根修 + 实时性**：①receipt payload 富化（模型 modelId/purpose/latencyMs；检索 family/query/resultCount/httpStatus，零 schema 变更）；②StageRecord.subtasks 仅真实总量处填充；③note 里程碑让假设逐条浮现、falsify 逐假设播报；④ActivityFeed 富化 + StageTimeline 真实计数；⑤**SSE 事件流**（Node 原生 http 零依赖，替代 2s 轮询，降级保轮询）；⑥多 run 后台感知条（active runs 迷你状态）+ web 通知（默认关、真实终态驱动）；⑦**版本对比视图**（side-by-side before/after + VersionDiff + 剩余不确定项，live v0→v1 真数据）；⑧PlanTab 质疑接线、ExperimentsTab i18n 硬化对齐。

## Wave 2 — 科学交互核心（思维碰撞，产品差异化所在）

**B4 对象级 AI 研究动作（指令 §5 核心，全新能力）**：每个假设/主张/计划可一键：Challenge（AI 接地反驳分析）、最弱前提探测、What would falsify this、Find evidence against（定向反证检索）、Ask（对象上下文问答）、What should I test next。新增 `POST /api/v1/runs/:id/actions`（服务端走既有模型网关，响应带 run 内真实证据接地与出处，流式呈现）；AI 分析标注模型出处，可一键转为 feedback 进入因果修订链——AI 输出不冒充事实。

**B5 假设操作完整性**：Fork（分叉为新候选，版本谱系）、Promote/Reject（人工裁决，入事件与反馈链）、Connect（人工绑定 claim↔hypothesis，与管线绑定并标 source=human）、对比画布导出 Markdown；决策点：run 级 lineage/项目分组（多 run 持续生长工作区）做域模型影响评估后定。

**B6 ACH 绑定增密（管线，科学评审强制）**：critique_falsify 扩展为全 claims×代表假设 支持/反对/**无实质关系** 显式判定（区分"未评估"），二次审校既有；绑定密度提升后 ACH 升级全量矩阵画布（显式空格语义）；过 SCIENTIFIC_TRUTH 评审。

**B7 证据图谱可视化**：claims–sources–hypotheses 关系交互图（SVG 自研零依赖：pan/zoom/极性着色/过滤/点击下钻 receipt），与 ACH/对比/证据表联动——Evidence Landscape 的首屏化。

**B8 实验执行进 run 生命周期（D-085 尾巴）**：orchestrator execute-stage 集成（RunStageName/STAGE_ORDER/runProgress 分母/长阶段租约续期），计划→实验→判决→修订工作台内闭环；专批红队对抗评审 + 回滚方案先行。

## Wave 3 — 入口与平台（摩擦≈0 + 正式产品级）

**B9 入口升级**：文本粘贴/DOI/URL/BibTeX·RIS（DOI/URL 走既有 OpenAlex 客户端）/Zotero 本地 API（localhost:23119 零依赖 fetch）/剪贴板自动识别（DOI/arXiv）/拖放区/语音（Web Speech API 浏览器原生）/截图图像（走模型网关视觉路由，决策点确认路由）；`POST /runs` 扩 seed 字段（用户供源入 verify 管线，provenance=user_provided）；PDF 二进制解析不进 Node（决策点：桌面 Rust 侧 or 诚实降级提示粘贴文本）。

**B10 桌面产品化（Tauri）**：系统托盘、全局快速捕获热键、原生通知、深链 `far://run/<id>`、文件拖放打开、单实例、窗口状态记忆、对比多窗口、server 不可见时优雅降级页（非白屏）；Rust 插件依赖落地当批按确认线报备。

**B11 CLI 成熟化**：`far completion`（bash/zsh/pwsh）、`far research status --watch` 流式等待叙事、交互式 `far new` 向导、错误分类+建议统一、帮助重写、全命令 `--json` 输出审计。

**B12 能力管理面**：模型路由管理器（各路由健康/延迟/用途/默认路由策略/探针触发，`far probe`+`/health` 既有能力，secrets 永不显示、配置指向 env）+ 检索族/实验适配器注册表 + 配置健康检查面；MCP 支持先做 OSS 尽调评估（build-vs-reuse 纪律），不盲目自建。

## Wave 4 — 品质与终局

**B13 信任/真相/无障碍硬化**：渐进披露完成度全查（技术细节全降级）；错误/空态/失败全产品统一组件（What failed/Why/Still valid/Unknown/Retryable/Changeable，AI 失败=正常态）；反证检索记录结构化展示；i18n 清零硬编码；科学排版（KaTeX 公式、长文、大表、中英双语排版）+ a11y 全面审计（纯键盘全程/对比度/缩放与字级/读屏语义/reduced-motion 全覆盖）。

**B14 性能与交互工艺终局**：①性能预算实测全指标（冷/热启动、导航、输入、搜索、TTFF 首证据、42-run 大列表、大 claims 表、图谱渲染、SSE 延迟、内存）超标即修（不加骨架屏遮丑）；②交互工艺 pass（§12 全清单：hover/select/focus/expand/collapse/drag/drop/create/delete/run/pause/cancel/switch/save/copy/error/success/partial，动效只服务方向/连续/因果/反馈）；③终局 dogfood：完整旅程量化对比 B1 基线；④独立对抗审计（adversarial-auditor + architecture-critic）P0/P1 修复复验；⑤completion-gate.mjs + 全量门禁 + 证据齐备。
