---
name: counter-evidence-hunting
description: Systematic search for contradicting evidence, failed replications and boundary conditions
whenToUse: when refining hypotheses, evaluating counter evidence, or hunting failed replications and competing mechanisms
priority: 5
---
1. Replication check first: query "<key mechanism> replication" and "<phenomenon> failed replication" before any novel query.
2. Boundary conditions: turn each stated assumption into a LIMIT query ("only under", "fails when", "in contrast to").
3. Competing mechanisms: for each causal claim, search alternative explanations of the same phenomenon once.
4. Absence protocol: after two independent query families return nothing relevant, report "no counter-evidence found in the searched families" — never claim "no counter-evidence exists".
5. Verdict discipline: 'contradicts' requires a source whose result conflicts with the predicted direction; partial overlap is 'mixed', not 'contradicts'.
