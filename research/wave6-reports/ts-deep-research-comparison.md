## 1. Architecture one-paragraphers

**DR (dzhng)**: Recursive breadth/depth tree. `deepResearch()` generates `breadth` SERP queries (with prior learnings injected), runs them through ONE commercial provider (Firecrawl), extracts ≤3 learnings + ≤newBreadth follow-up questions per result, then recurses with `depth-1` / `ceil(breadth/2)` using a synthesized next-query string. Final report is written from the learnings list only; visited URLs appended as a flat "## Sources" list. No sufficiency evaluation, no token budget, no retry.

**JR (jina)**: Token-budgeted single-agent while loop (`getResponse`) choosing one action per step (search / visit / reflect / answer / coding) via a zod union schema whose branches are dynamically enabled/disabled by state. The loop is closed by a two-stage evaluator: the QUESTION is pre-classified into evaluation types (definitive/freshness/plurality/completeness + forced strict), and every ANSWER attempt must pass those checks (fail-fast, budgeted retries); failures trigger an error-analyzer whose recap/blame/improvement is fed back as a knowledge item, and a strict-reviewer improvement plan is injected into later answer prompts. Post-loop: finalizer rewrite (with length guard), embedding-based claim↔chunk citation binding with [^N] footnote injection and a Jaccard fallback, OpenAI-compatible SSE streaming of think/search/visit progress.
