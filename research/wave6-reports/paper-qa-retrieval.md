## Cross-cutting observations for FAR-Lab

1. **The retrieval face is two-pipeline**: lexical BM25 over a local corpus (search.py) for *paper discovery*, and embedding+LLM over chunks (docs.py/core.py) for *evidence extraction* — joined by a shared `Docs` state. FAR-Lab's API-families + abstract-pool design collapses both into one stage; the split is the more scalable shape if full text ever enters scope.
2. **Every LLM judgment is paired with a deterministic verifier**: JSON scores → regex re-extraction fallbacks (extract_score), citation keys → closed-set parse+strip, provider titles → Jaccard gate, docs → entropy gate. This mirrors FAR-Lab's zod-only + verify-stage philosophy; the citation-binding verifier (3.3) is the piece FAR-Lab has no equivalent of.
3. **Failure granularity is per-item**: one bad context/DOI/provider never fails the query (client_models.py:109-143; core.py:383-400; docs.py:573-585). FAR-Lab should confirm its retrieve stage degrades per-family/per-item rather than aborting the pool.
4. **Negative finding**: year filtering advertised but unenforced (4.3); FAR-Lab should implement it server-side when adding recency control.

## TOP-5 ranked mechanisms for FAR-Lab source-level fusion

Ranked by (value to Direction-A hypothesis/evidence chains) × (fit with no-embedding + 3-keyless-source constraints) ÷ port cost:

1. **pqac citation-binding contract** — opaque 8-char context ids (types.py:249-316), prompt-side valid/invalid key examples + Valid Keys line (prompts.py:38-69; settings.py:1270-1273), deterministic parse→docname replacement + hallucination-strip + bib-from-cited-only (types.py:474-526, utils.py:170-194), adversarial test matrix (tests/test_paperqa.py:3422-3534). *Port cost: small. Zero embedding dependency. Gives FAR-Lab claim→evidence-span provenance, the current biggest gap between "papers found" and "scientifically bound hypotheses".*
2. **Per-evidence LLM extractive summary + 0-10 relevance gate** (docs.py:492-586; core.py:178-400; prompts.py:108-119) — turns retrieval candidates into grounded, quote-preserving, citable Context objects with per-item failure isolation; score-ordered capped serialization (settings.py:1202-1273). *Port cost: small-medium. Complements (not replaces) RRF+listwise rerank; the Context objects become the things pqac-style ids bind to.*
3. **Search-query decomposition with broad/narrow diversity + year ranges + continuation cursors** (helpers.py:27-75; tools.py:118, 167-210). *Port cost: small. One prompt upgrade to the existing plan call plus an offset memory; year ranges must be enforced server-side (paper-qa's own 4.3 gap is the cautionary tale).*
4. **Provider merge-with-preference + canonical identities** (clients/__init__.py:84-264; types.py:910-938, 1267-1371; semantic_scholar.py:167-173) — DOI/arXiv canonicalization, doc_id=md5(doi+content_hash), prefer-newer merge, hydration early-stop, author cross-check on imperfect title matches (semantic_scholar.py:138-155, 278-292). *Port cost: medium. Turns FAR-Lab's dedup-by-id into enriching merge across its existing three keyless families; author cross-check is a direct verify-stage upgrade.*
5. **Citation-string quality signals** (types.py:787-792, 1216-1249; retractions.py; journal_quality.py) — citation_count + venue tier + retraction flag injected into the evidence text the reasoning model sees. *Port cost: small (OpenAlex already returns cited_by_count; retraction flag optional). High leverage for supporting-vs-counter-evidence weighting, which is FAR-Lab Track-1 core.*
