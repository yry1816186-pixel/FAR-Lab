## System shape (one paragraph)

OpenScholar = offline dense retrieval (Contriever `akariasai/pes2o_contriever` over peS2o v3, 45M papers / 200M+ 256-word-chunk embeddings, FAISS flat; `retriever/api/pes2o_ds.py:15-49`, `retriever/api/conf/pes2o.yaml:13-19`, README.md:174-178) fused with online API retrieval (Semantic Scholar keyword search + LLM query expansion + ar5iv fulltext scrape: `src/use_search_apis.py:96-246, 478-513`) and optional web search (site:arxiv.org OR pubmed: `use_search_apis.py:279-384`), then cross-encoder (BGE) passage rerank with citation priors (`src/open_scholar.py:40-65, 120-140`), generation with inline `[n]` citation discipline (`src/instructions.py:80-104`), optional self-feedback loop with retrieval (`open_scholar.py:639-700`), and optional posthoc attribution insertion for uncited statements (`open_scholar.py:527-604`). BM25 (Pyserini/Lucene) exists as an alternative retriever path (`retriever/src/search.py:765-824`, `retriever/src/index.py:401+`). A separate Flask API serves the dense index (`retriever/api/serve_pes2o.py:96-111`).
