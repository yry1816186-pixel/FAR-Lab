- JSON Schema 文件全部由 TS 类型经 `generate_json_schema.mts` 生成，禁止手工编辑，变更类型后必须重跑脚本并通过 `--check` 验证。
- 数据库迁移采用严格递增的三位数字前缀（0001~0025），版本号必须连续且不得存在空占位迁移。
- 所有可追加写入的核心表通过 BEFORE INSERT/UPDATE 触发器强制 append-only（禁止 UPDATE/DELETE），以维护哈希链不变性。
- 枚举字段同时使用列级 CHECK 约束与触发器双重守卫（如 verdict/conclusion 的 enum guard），实现防御纵深。
- 对外 API 统一使用 `{ ok: true, data: T }` 信封 + RFC 7807 错误响应的 V2 receipts 风格。
