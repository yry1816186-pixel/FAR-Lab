本模块按契约类型划分为三个并列子目录：
- `json/`：存放由 `scripts/generate_json_schema.mts` 从 TS 类型（`src/fec/fec_contract.ts#FecContractV2`、`src/proof_envelope/types.ts#ProofEnvelope`、`src/schema/enums.ts#VERDICTS`、`src/far_proof/exporter.ts#DataManifest`）机器生成的 JSON Schema 文件（`fec.schema.json`、`proof-envelope.schema.json`、`verdict.schema.json`、`data-manifest.schema.json`），禁止手工修改，通过 `--check` 模式做漂移校验。
- `migrations/`：按 0001~0025 连续编号的 SQLite 迁移 SQL，由 `src/db/migrator.ts` 在启动时顺序执行；设计为仅向前（forward-only），无 down 路径，因为核心证据表带有 append-only 触发器以维持哈希链，任何回滚都会破坏链完整性；版本必须连续且无占位迁移。
- `openapi.json`：描述对外 HTTP API（含 `/health`、`/ready`、`/metrics`、`/api/v1/*` 等端点），采用 RFC 7807 错误响应格式。
依赖方向单向：TS 源码 → 生成 schema/json；业务演进 → 新增 migrations；API 变更 → 更新 openapi.json，三者共同构成 FAR-Lab 的数据契约层。
