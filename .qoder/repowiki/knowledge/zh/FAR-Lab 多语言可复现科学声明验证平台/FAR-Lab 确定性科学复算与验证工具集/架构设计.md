模块按职责划分为四个子包：
- `far_chain_repro/`：核心复算引擎，以 `calc_bridge.py` 的 `ReproContext`（model_snapshot + active_model_ids_sorted + CalcSpec + env_hash）通过 `canonical_json` 生成 sha256 repro_hash；`verify_chain.py` 基于 SQLite 与 JSON 路径做链式 current_hash 校验；`proof_hash.py`、`verdict_kernel_v2.py`、`merkle_root.py` 分别实现 ProofEnvelope V2、五值裁决内核与 Merkle 树的 Python 镜像；`ast_guard.py`、`math_input_hash.py`、`golden_vectors.py`、`deterministic_seed.py`、`cross_lang_roundtrip.py` 提供 AST 扫描、输入哈希、E4 黄金向量、固定种子与 TS↔Python 往返一致性闭环。
- `math_backends/`：独立可执行脚本（`sympy_backend.py`、`z3_backend.py`），由 TypeScript 层通过 `python <script>` 以 stdin/stdout JSON 协议调用，约定永不崩溃、统一使用 `json.dumps(sort_keys=True, separators=(',',':'))` 输出以保证跨语言 canonical hash 对齐。
- `science_harness/`：`sandbox_runner.py` 作为 venv 沙箱执行器，注入固定 seed、threadpoolctl nthread=1、网络策略与审计钩子（拒绝 ctypes.dlopen/subprocess/os.exec 等），并以标准化 JSON receipt 返回资源用量；`dataset_fetch.py` 负责 lightkurve/astroquery 在线数据集拉取。
- `real_paper/`：针对论文中 bem_statistics 与 osc_replication 的重算脚本。
依赖方向单向：`science_harness` 与 `math_backends` 被上层 TS 或测试调用，`far_chain_repro` 内部各子模块通过 `__init__.py` 统一 re-export，不反向依赖其他子包。
