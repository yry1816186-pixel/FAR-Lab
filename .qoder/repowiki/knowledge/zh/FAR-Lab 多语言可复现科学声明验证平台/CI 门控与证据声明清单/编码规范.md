- smoke 脚本统一通过 `import.meta.url === pathToFileURL(process.argv[1] ?? '').href` 判断是否被直接执行，再调用 `main()` 导出函数，避免被 import 时副作用执行。
- 对外部 SDK 返回类型采用自定义 type guard（如 `isChatCompletion`）进行运行时收窄，禁止直接使用 `as any` / `as unknown as` 强转。
- 关键断言集中封装为本地 `assert(condition, message)` 或 `fail(message)` 辅助函数，失败时输出带前缀的日志并以非零退出码终止 CI。
- YAML 清单文件顶部以注释块声明其对应的规范编号（如 CORE-CLAIM-001、ENG-TEST-001）与维护契约，供 CI lint 脚本引用。
- 所有 smoke 脚本遵循“零容忍合规”约定：禁用 `any`、`@ts-ignore`、双重断言、空 catch 和桩代码返回，确保 CI 行为可被源码级审查。
