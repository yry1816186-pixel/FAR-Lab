本模块为扁平的脚本集合，按职责分为若干子域：
- 需求治理：`requirements_compile.mjs` + `requirements_registry.mjs` 构成从 `.far/constitution` 到 `.far/requirements` 五件套（REQUIREMENTS/ACCEPTANCE/COVERAGE/OWNER_MAP/GATES.yaml）+ `COMPILE_RECEIPT.json` 的单向编译管线，通过 `--check` 模式实现漂移检测。
- 代码质量门禁：`complexity_budget_check.mjs`、`perf_budget_check.mjs`、`coverage_gate.mjs`、`mutation_gate.mjs`、`repo_hygiene_gate.mjs`、`test_risk_map_check.mjs`、`doc_command_check.mjs`、`claim_lint.mjs`、`novelty_wording_lint.mjs` 等各自独立运行，输出 PASS/FAIL 并配合 `complexity_budget_baseline.json`、`perf_budget.json` 等基线文件做增量/豁免管理。
- 安全与供应链：`secret_scan.mjs`、`license_audit.mjs`、`check-supply-chain.mjs`、`zero_tolerance_scan.mjs`、`no_llm_final_judge_scan.mjs`。
- 发布与交付：`release_check.mjs`、`verify_release_checksums.mjs`、`publish_to_zenodo.mjs`、`generate_sbom.mjs`、`make_demo_pack.mjs`。
- 文档与演示渲染：`build_report_ppt.py`、`export_pdf.py`、`gen_figs.py`、`qa_ppt.py`、`render_ppt.py`、`jsdocs_scan.py`。
- 测试辅助：`run_py_tests.mjs`、`test_capture_run.mjs`、`test_failure_capture.mjs`、`test_numbers_check.mjs`。
- 跨语言依赖安装：`install.sh`、`install.ps1`、`ensure_native_deps.mjs`、`ensure_py_deps.mjs`。
所有脚本以 `#!/usr/bin/env node` 或 Python shebang 自包含入口，通过 `process.exit(0|1|2|3)` 表达明确退出码语义；多数脚本同时支持 CLI 直接执行与作为模块被其他脚本 import（使用 `if (import.meta.main)` / `if (process.argv[1]?.endsWith(...))` 守卫）。
