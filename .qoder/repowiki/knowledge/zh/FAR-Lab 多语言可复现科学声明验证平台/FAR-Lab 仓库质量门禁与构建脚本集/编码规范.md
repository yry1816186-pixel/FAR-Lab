- 每个脚本顶部 JSDoc 注释说明用途、参数、退出码语义，并在主函数中统一通过 `parseArgs` 解析 `--flag value` 形式的命令行参数。
- 脚本以 `process.exit(0)` 表示成功、`process.exit(1)` 表示门失败、`process.exit(2)` 表示参数错误、`process.exit(3)` 表示规范源缺失等约定化退出码。
- 脚本既可作为 CLI 直接执行，也可被其他脚本 import 复用其导出函数，通过 `if (import.meta.main)` 或 `if (process.argv[1]?.endsWith('xxx.mjs'))` 守卫 main 入口。
- 对外部命令调用统一封装为 `git(args)` 或 `execFileSync` 包装器，捕获异常并以 `{ code, out }` 结构返回，避免未处理拒绝。
- 白名单/允许列表采用 `Set` 或数组常量集中声明（如 `ALLOW_FILES`、`ALLOW_DIRS`、`REQUIRED_RISK_CLASSES`、`ASSET_KINDS`），便于与治理规范保持同步。
- 门禁类脚本输出固定前缀日志（如 `xxx: PASS` / `xxx: FAIL` / `[DEBT] ...` / `[FAIL] ...`），便于 CI 日志解析与聚合。
