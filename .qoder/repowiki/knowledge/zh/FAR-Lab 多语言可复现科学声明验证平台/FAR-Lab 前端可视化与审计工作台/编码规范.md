- 所有 API 调用集中在 src/lib/api_client.ts，通过 useQuery/useMutation 暴露为 React Query hooks，并以 queryKeys.* 常量作为稳定查询键，禁止在页面中直接写 fetch。
- API 响应在边界统一解码：V1 走 parseV1Response 校验 { ok: true, data } 信封，V2 receipts 走 parseV2Response 结合 Zod schema 做运行时校验，失败均抛出带 errorCode 的 ApiError。
- 页面路由一律通过 React.lazy + Suspense 懒加载，配合 vite.config.ts 的 manualChunks 将 d3、react、react-query 等依赖拆为独立 vendor chunk 以提升缓存命中率。
- 导航项集中声明于 AppShell.tsx 的 NAV_GROUPS 数组（primary/tools 两组），路由与标题映射由此单源生成，禁止在多处维护 route→label 映射。
- 样式全部通过 Tailwind 类名组合，颜色/字体/阴影等设计令牌经 tailwind.config.ts 扩展并映射到 CSS 变量，组件内不出现硬编码十六进制色值。
- 测试通过 src/test-setup.ts 全局注入 fetch mock、Node webcrypto、matchMedia 和 scrollTo no-op，并在 afterEach 中清理 DOM 与 mock 记录，避免用例间污染。
