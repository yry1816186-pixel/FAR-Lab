模块以 src/main.tsx 为入口挂载 React 应用，src/App.tsx 通过 react-router-dom 注册全部路由并使用 React.lazy 实现页面级代码分割（d3 等重型依赖被隔离到 Viz/Ablation 等懒加载 chunk），并通过 @tanstack/react-query 提供全局数据缓存与重试策略。
分层结构清晰：
- pages/：按功能划分的页面组件（ResearchWorkbench、Viz、Integrity、Court、Arena 等），每个页面对应一个路由；
- components/：跨页面复用组件，细分为 layout/（AppShell、Logo、PageHeader）、theme/（ThemeProvider 亮暗主题切换）、ui/（基于 Radix + shadcn 风格的原子 UI 组件如 button/card/dialog/table）以及业务组件（ErrorBoundary、EvidenceTimeline、IntegrityBadge、VerdictBadge、RouteEffects 等）；
- lib/：纯函数与 hooks 层，核心是 api_client.ts（封装 fetchJson/fetchText、统一错误解析、TanStack Query hooks、SSE 事件流订阅、V1/V2 响应信封解码器 parseV1Response/parseV2Response）和 research_client.ts（研究工作流专用客户端），另有 types.ts、schemas/（Zod 运行时校验）、i18n/、merkle.ts、verdict.ts、uncertainty.ts、vizHonesty.ts 等工具库；
- __tests__/：基于 Vitest + jsdom + @testing-library/react 的页面与单元测试。

构建与部署由 vite.config.ts 集中管理：使用 esbuild target es2022 避免 lucide-react 解构降级问题，通过 Rollup manualChunks 将 vendor-react/vendor-d3/vendor-query 拆分为独立缓存 chunk；开发服务器代理 /api/v1、/health、/ready 至后端 localhost:3000，生产通过反向代理或 VITE_API_BASE_URL 环境变量切换同域/跨域模式。样式体系基于 Tailwind CSS 3 + tailwindcss-animate，在 tailwind.config.ts 中定义设计令牌（brand 主色、verdict 裁决色阶、字体族、字号阶梯、阴影与动效曲线），并通过 CSS 变量支持亮/暗主题。
