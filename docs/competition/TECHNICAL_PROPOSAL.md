## 1. 摘要（科学价值：准确性·清晰性·完整性）

科学发现依赖两件事：**可证伪的假设**与**可执行的研究计划**。当前 LLM 直接生成科学假设
存在三类系统性缺陷：①不可证伪（结论无法被实验否定）；②不可追溯（引用无法核对到真实文献，
可编造 DOI 与论文）；③不可复现（同一问题两次运行结果漂移，无法审计）。

FAR-Lab 是一个**证据约束、可证伪、可迭代、可追溯**的开源 AI Scientist 科研系统。它的核心
设计原则是角色分离：**LLM 只负责提出，确定性内核负责裁决，第三方可以独立重算**。系统从
科学问题出发，执行七步纵向闭环：

```
科学问题 → ①研究可行性门 → ②真实文献检索(支持+反证) → ③候选假设生成(3-5个·机制不同)
        → ④独立批判 → ⑤引用绑定+确定性评分+Pareto 前沿 → ⑥可执行研究计划
        → ⑦反馈修订(人工/文献/工具) + 真实数据分析 → 下一轮
```

本方案面向《Science》125 个前沿科学问题，基座模型为 Qwen 系列（阿里云百炼），真实文献
检索基于 OpenAlex/arXiv/Crossref，真实数据分析基于 NASA Exoplanet Archive（公共领域数据）。

---

## 2. 系统架构

三层结构，各层边界清晰：

| 层 | 职责 | 关键组件 |
|----|------|---------|
| 生成层 | 假设生成、研究计划、问题分解 | Qwen（百炼）；离线回放用于确定性测试 |
| 信任层 | 裁决、评分、引用绑定、可证伪契约 | R0–R9 确定性裁决内核、FEC 可证伪契约、内容寻址证据链 |
| 交付层 | 复现包、审计、入口 | `.far-proof` 导出、CLI/API/Web 三入口共享同一 application service |

三个入口（CLI `far research` / REST `POST /api/v1/research` / Web `/research` 工作台）调用
**同一个** application service——不存在 CLI 与 API 行为漂移。

---

## 3. 研究可行性门与问题分解（§9.1/§9.2）

任何问题在进入检索前先过**确定性筛查**（无 LLM，纯离线可测）：
- 长度边界、非科学问题模式识别（创作/闲聊类提示 → `UNSUPPORTED` 拒绝，exit 3，不伪造管线）；
- 安全筛查：高危化学（爆炸物合成）、双刃生物学、人体试验方向 → 拒绝或要求伦理门。

通过后由 Qwen 做**问题分解**：已知事实、未知变量、关键定义、可观测量、候选机制、主流/替代
理论、检索子问题（≤6 条，直接注入后续检索）、混杂因素、数据需求、可证伪条件、不可区分
场景。分解的检索子问题使检索覆盖**支持性证据之外的分解子问题与反证**。

---

## 4. 真实文献检索与证据绑定（§9.3）

- 检索查询三来源：原始问题 + **反证查询**（自动生成"证伪/零结果/替代解释"类查询）+
  分解子问题；每个查询有界（默认 5 篇/查询）。
- 语料按 SHA-256 内容寻址形成 `CorpusSnapshot`（snapshotId=哪些论文，rootHash=确切内容，
  篡改可检测）。
- **引用绑定**：模型只能引用语料 allowlist 中的 documentId；未绑定的引用被确定性计数，
  不能成为有效证据（实测 `citationBindingRate=1.0`，`unboundEvidenceCount=0`）。
- 文献身份真实性：documentId 由 (来源, 持久标识) 确定性哈希得出，模型无法铸造有效 id。

---

## 5. 假设生成、批判与评分

- **生成**：语料注入 + 引用 allowlist，要求 3-5 个**机制不同**的候选假设（内容寻址 id
  去重，同义改写会塌缩为同一 id），每个假设必须携带完整可证伪方法（指标+比较方向+阈值）。
- **独立批判**：对每个假设做对抗审查（可证伪性/新颖性/反证缺失/相关非因果/选择性报告/
  引用不匹配等 9 维度）；批判与生成同模型时**如实标注** `sameModelAsGenerator`。
- **评分**：确定性维度（Falsifiability、Testability、EvidenceCoverage、
  CounterEvidenceCoverage、Risk——由绑定与可证伪结构程序化计算）+ 模型维度（显式标注来源）；
  **模型永不产出单一总分**；Pareto 前沿标注非支配假设；主假设由确定性维度排序选出（可重算）。

---

## 6. 可执行研究计划

计划不是段落文本而是结构化契约：目标、预注册预测、数据需求、纳入/排除标准、变量、
**分析 DAG**、工具、统计方法、样本量论证、多重性处理、缺失/离群策略、**停止条件**、
检查点、预算、风险、可复现声明、下一轮决策规则、**人工批准门**（`humanApprovalRequired`）。
实测计划完整度 1.0。

---

## 7. 反馈、修订与真实数据闭环

- 反馈是**类型化信号**（来源：人工/文献/工具/分析；触发器：重检索/换假设/重写计划），
  不是聊天记录追加；修订**不可变、可比较、可回滚引用**（父 id + 冻结 before/after 计划
  快照 + 结构化 diff）。
- **真实数据分析**：NASA Exoplanet Archive live TAP 抓取 → 辐照度 + Pearson 相关
  （t 变换双侧 p）+ Fisher-z 置信区间（权威参考：Fisher 1921；对照：Anscombe 四重奏）。
  **2026-08-14 live 实测**（runId `01KZZ74P2YEEN0BTBD1V4KK9PD`，mode=LIVE）：
  n=392 颗热木星 r=0.587、p<0.001、95% CI [0.518, 0.649]——与辐照驱动膨胀文献一致；
  表述严格限定为"相关性，非因果"。
- **人工反馈→修订实测**（同一 runId）：reviewer 要求控制样本（Ca II H&K S-index 匹配
  入射通量）+ 预注册区分假设的实验 → 修订 #2 真实改写计划（+4 人工批准门、贝叶斯因子
  决策规则、预注册要求），前后差异可 compare。
- 观察结果 → 反馈信号 → 修订的真实影响：显著→记录关联；不显著→触发替代假设（**零结果
  如实保留，绝不伪造确认**）；样本不足→触发计划重写（修订可能使计划更保守——如实记录）。

## 8. 运行模式诚实标注与逐阶段溯源（§3.2/§3.3）

- 每个阶段记录组件模式（`modelExecutionMode`/`retrievalExecutionMode`/`experimentExecutionMode`），
  聚合 `runMode` 仅当所有影响科学的组件均 live 时为 `LIVE`；`MIXED`/`RECORDED_REPLAY` 如实
  展示，绝不伪装 live。
- 每条运行产出 10 条逐阶段 ProvenanceReceipt：provider/模型 id/请求 id/快照状态/提供商
  报告的 token 用量/成本状态/语料哈希/输入输出哈希/环境指纹（git commit、工作树脏标志、
  锁文件哈希、Node 版本）/重试次数/finish reason。**提供商未提供的字段为 null +
  provenanceStatus=partial 并列出缺失项——绝不虚构**。
- **可证伪门实测**（live runId 同上）：Qwen 生成的 3 个假设中 2 个的 falsificationMethod
  不完整（缺阈值）→ 确定性门如实判 F（`falsifiabilityCompleteness=0.333`），主假设仅从
  "全绑定 + 可证伪"候选池选出——模型输出被确定性规则约束，而非照单全收。

---

## 9. 确定性验证内核与复现包（可复现性）

- **确定性重算**：`far research verify` 从冻结输入重算语料 rootHash、引用绑定、确定性
  评分维度、Pareto 前沿、主假设选择并与存储值比对（模型文本明确标注为不可逐位复现——
  诚实边界）。实测 PASS。
- **导出包**：`far research export` 产出哈希钉住 bundle（run JSON + manifest + 零依赖
  verify.mjs + README 诚实边界说明）；第三方可独立验证完整性；篡改任一字节 → exit 7。
- **程序化评估**：13 项指标由脚本从冻结运行状态计算（引用绑定率、未绑定证据数、假设数
  与去重 id 数、可证伪完整率、反证查询数、计划完整度、修订数、观察数、收据完整度、
  人工批准门数、门裁决、运行模式）；**人工 rubric 指标（文本科学合理性等）明确列出、
  绝不自动打分**。

## 10. 评估方法与四类公平基线（§14）

- **冻结评估集**：6 项（1 个深入 hero + 5 个《Science》125 问题），显式覆盖五种证据状态
  （支持/冲突/反证/零结果/无定论）；开放问题**不伪造 ground truth**——评估引用诚实性、
  可证伪性与计划质量。
- **四类公平基线**（同模型、同问题、同冻结指标）：①Qwen 单次直答 ②Qwen+简单 RAG ③同模型
  同工具但无确定性内核（模型自评分选优）④完整系统。能力缺口报 **N/A**（诚实），绝不记
  0 分。**2026-08-14 live 实测**（同 key 同问题，全部 mode=LIVE）：
  direct=6 假设（无语料/无绑定/无内核）；rag=5 假设+14 文档（无绑定验证/无内核）；
  no_kernel=4 假设（无内核）；**full=3 假设+37 文档语料+binding 1.00+unbound 0+确定性
  内核 yes**——引用绑定与确定性裁决是完整系统独有的能力，而非参数差异。

## 11. 安全与诚信边界

- 无 secret 明文；key 引用一律环境变量名（`far doctor` 只检查存在性不读值）。
- 危险方向（爆炸物合成、双刃生物）在可行性门拒绝；人体试验/个人数据方向要求伦理门。
- 所有 CI badge 指向真实 workflow；demo 输出标注 fixture 来源；「已验证」全部可回溯到
  命令输出与测试名。零容忍扫描（`:any`/`@ts-ignore`/空 catch/硬编码 secret）全绿。

---

## 12. 已知边界

1. LLM 生成文本不可逐位复现（明确标注为不可复算项，冻结而非重生）。
2. 相关性分析不构成因果结论；单数据集快照（有界 TOP 400）非穷尽。
3. live 依赖 DASHSCOPE_API_KEY；无 key 时系统 fail-closed 提示并显示
   RECORDED_REPLAY 模式，绝不静默降级伪装 live（CI 冒烟测试无 key 时显式 skip）。
4. 「全自动科学家」不在目标内：人类批准门是一等公民。

---

## 13. 结论

FAR-Lab 把 AI 科学假设生成从「模型说可信」升级为「**可证伪、可追溯、可独立重算**」——
一条命令完成证据约束的假设生成与研究计划设计，真实文献与真实数据在闭环中运行，确定性
内核约束模型幻觉，第三方可以验证结果没有被篡改。这正对应赛道一·方向 1·A 对科学价值
（准确/清晰/完整）、技术深度（校验反馈迭代稳定）与应用潜力（真实场景/可复现）的三维要求。
