Before any external Alpha, controller/processor identity, jurisdiction, lawful basis, DPA/subprocessor list, exact retention, deletion propagation, backup expiry, incident notice, and data-subject rights must replace all provisional/TBD policies. Provenance records that cannot lawfully retain personal data require pseudonymous identifiers or scoped tombstones; “append-only” is not an exemption from privacy law.
