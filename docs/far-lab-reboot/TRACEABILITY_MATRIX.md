# Traceability matrix

Each `TR-*` is one stable chain. The two tables join on Trace ID; together they implement:

`problem → stakeholder → JTBD → service → requirement → interface → domain/component → data/event → permission/policy → risk → acceptance/test → metric/SLO → operations/support → version/release`.

No row describes current implementation completion. `BLOCK` means its release gate remains closed.
