## 一、愿景与不可变原则

### 1.1 一句话愿景

> **FAR-Lab 是 AI 科研的确定性测谎仪——用数学规则(不是另一个AI)验证AI做出的科学发现是否被数据支持,并生成任何人可以独立复算的证据包。**

### 1.2 五条不可变原则

| # | 原则 | 理由 | 违反后果 |
|---|------|------|---------|
| **P1** | **确定性裁决核永不引入 LLM 裁决** | 用 LLM 验证 LLM = 用魔法打败魔法,不可靠。R0-R9 规则树是核心 IP。 | 丧失唯一差异化优势 |
| **P2** | **每项裁决必须可溯源到具体规则+证据** | 科学验证的核心是可审计性。黑箱裁决 = 无价值。 | 评委质疑可信度 |
| **P3** | **验证包必须可被任何人独立复算** | 信任不应该是"相信我",应该是"你自己算"。.far-proof 的核心价值。 | 退化为又一个黑箱工具 |
| **P4** | **五值裁决永不退化为二值** | 科学不是非黑即白。CONFIRMED/REFUTED/INCONCLUSIVE/DEGRADED_SCOPE/UNTESTED 保护科学诚实。 | 过度承诺导致名誉风险 |
| **P5** | **数据不离用户设备(隐私优先)** | 验证他人研究只处理公开数据。不收集、不上传、不追踪。 | 法律/伦理风险 |

### 1.3 三个不变量(已验证成立,抗过时性 A-)

来自 `docs/anti-obsolescence-report-2025.md`(33个来源):
1. **LLM 会幻觉** — 幻觉是自回归模型结构性特征(Cornell/Northwestern 2024 学术共识),即使 GPT-5 困难任务仍 30% 幻觉率(HalluHard 2025)
2. **科学需要可复现** — 科学的 foundational principle
3. **信任需要第三方验证** — 人类社会的 foundational principle

## 四、数据模型

### 4.1 核心实体关系

```
Claim (科学声明)
  │ 1:1
  ▼
FEC (可证伪性执行契约)
  │ 1:N
  ▼
Evidence (证据项)
  │ N:1          │ 1:N
  ▼              ▼
Dataset ←── Measurement (测量值)
                   │ N:1
                   ▼
              ExecutionTrace (执行轨迹)
                   │ 1:1
                   ▼
              Verdict (裁决)
                   │ 1:N
                   ▼
              AntiTheaterFinding (检测发现)
                   │
                   ▼
              ProofEnvelope (证据信封)
                   │ N:1
                   ▼
              .far-proof Bundle (验证包)
```

### 4.2 关键数据结构(已有,基于代码)

- **VerdictKernelInput**: 17字段(spec/dataset/statistics/protocol/antiTheater/scope/power...)
- **VerdictKernelOutput**: decision(5值) + decisiveRuleId + reasonCodes + statisticalReport
- **.far-proof**: JSON + SHA-256 hash chain,包含 claim_graph/integrity/proof_envelopes/otel-trace/prov.ttl/repro_runs

## 五、对抗式设计(每个检测器的攻防)

### 5.1 检测器攻防矩阵

| 攻击类型 | 检测器 | 攻击方式 | 反制措施 | 当前状态 |
|---------|--------|---------|---------|---------|
| p-hacking(α操纵) | phack_alpha | 偷换显著性阈值 | FEC冻结α,核对比 | ✓ |
| p-hacking(校正缺失) | phack_correction | 多重比较不做Bonferroni | 检测校正声明 | ✓ |
| optional stopping | optional_stopping | 逐次看结果选择停止时机 | 要求spending function | ✓(静态) |
| seed cherry-picking | seed_cherry | 只报告有利seed | 多seed注册审计 | ✓ |
| 数据集漂移 | dataset_drift | 换数据集不声明 | 数据集hash绑定 | ✓ |
| 伪造PASS | fake_pass | 声称验证通过但无证据 | requiredEvidence resolve检查 | ✓ |
| 范围洗钱 | scope_launder | 缩小scope获得正面结果 | scope mismatch检测 | ✓ |
| 报告不匹配 | report_mismatch | 论文写的和实际跑的不一致 | executionTrace对比 | ✓ |
| 工作流篡改 | workflow_digest | 修改pipeline代码 | workflow hash绑定 | ✓ |
| 标识符伪造 | R_IDENTIFIER | 编造不存在的数据集ID | 外部标识符解析验证 | ✓ |
| 推导形式不匹配 | R_DERIVATION | 声称的推导与实际不符 | 形式化推导检查 | ✓ |

### 5.2 已知绕过路径(诚实声明)

1. **optional_stopping 仅静态检查**: 当前只读FEC冻结的stoppingRule字符串做关键词匹配,不做运行时alpha累积重算(W5 ROADMAP)
2. **检测器只在Golden Vectors上验证**: 未验证真实论文(GAP-003)
3. **数据来源依赖FEC绑定**: 如果FEC本身被恶意构造,检测器只能检查FEC内部一致性
