# Code Snapshot

Code is **not** copied into this export. The authoritative code snapshot is the git
commit `ffffffffffffffffffffffffffffffffffffffff` (HEAD at time of computation).

Fresh-clone replay:
```bash
git checkout ffffffffffffffffffffffffffffffffffffffff
pnpm install --frozen-lockfile
pip install -e .
```

Honesty: code is verified only against the recorded HEAD — no formal verification (V3 roadmap).
