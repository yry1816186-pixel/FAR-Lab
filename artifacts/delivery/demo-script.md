# FAR-Lab 演示视频脚本与分镜（≤10 分钟）

> 原则（零表演红线）：全程**真实 run 真实页面**录制；不剪辑造假；若现场出现失败路径，如实展示恢复（这本身就是卖点）；每个画面绑定真实命令/页面——录制者按本脚本逐字可复现。括号内为画面/操作说明，非念白。

## 0:00–0:40 开场：产品一句话 + 路由健康（真实状态）

- 画面：终端。
- `node dist/cli/main.js probe`（配置态：逐路由 key 状态，无网络）
- 念白：「FAR-Lab，科学方法操作系统：不卖 AI 答案，卖可审计的科学决策过程。先看真实状态——三条模型路由就绪情况如实显示。」
- 【诚实点】若某路由缺 key，念出它：例如「百炼路由待凭证，探针一条命令可验」。

## 0:40–1:30 启动与提问（CLI 真实管线）

- 画面：终端 + `node dist/cli/main.js research start "什么机制驱动医院环境中抗生素耐药基因的水平转移？" --domain microbiology`
- 念白：一条真实科研问题进入 11 阶段管线；CLI 同步执行（租约单写者）。
- 备选（并行画面）：`npm run serve` 起本地工作台，浏览器开 `http://127.0.0.1:3196`。

## 1:30–3:00 检索透明（证据 tab·检索透明面板）

- 画面：Web 工作台 → 选中 run → 证据 tab 顶部面板。
- 逐行指出：**琥珀色「反证」徽章的两条查询**（结构性保证，双源执行）；各源命中数（与回执按查询文本 join 的真值）；融合行（池 39 · 重排已应用 · 反证保留席位 4 · 恢复变体 N）。
- 念白：「检索不是黑盒——系统被 schema 强制执行反证搜索，且每条查询的命中数来自真实回执。」

## 3:00–4:30 证据约束（证据 tab·证据行）

- 画面：claims 列表。指出认知状态字形：`✓`（已验证·绿，逐字绑定+来源下钻）、`✗`（未解析·红）、`▲`（对齐存疑）。
- 点开一条 claim 的引用块 → 跳转来源行（hash/验证方式）。
- 念白：「彩色只表达证据语义——对不上来源就降级，绝不编造。」

## 4:30–6:00 假设与锦标赛（假设 tab）

- 画面：锦标赛表（BT 分数+胜负平+胜率）→ 展开 matches（双序裁决+rationale）→ 假说卡：九字段证伪规范折叠展开（观测/测量/判定规则/证伪条件…）+ 完整性检查徽章 + 文献邻居判定。
- 念白：「排序依据可审计——每一对比较留裁决理由；每条假设是一份可证伪承诺。」

## 6:00–7:00 人在环反馈修订（概览 tab → 修订 tab）

- 操作：概览页反馈表单提交一条真实反馈（source=human_expert，如「请更重视菌株水平差异」）→ `research resume <run-id>`（或 Web 恢复按钮）→ 修订 tab 展示因果链：反馈→修订（逐字段 before/after + 质量增量）。
- 操作：溯源 tab 点「重新导出（含最新修订）」→ 新 bundle chip 出现。
- 念白：「修订是因果的——每条改动链接触发它的反馈，可逐字段审计。」

## 7:00–8:30 第三方独立核验（信任闭环 = 独有能力）

- 画面：终端。`node dist/cli/main.js research export <run-id> --format bundle --out out/` → `node dist/cli/main.js verify <bundle-id>`
- 逐行念出 10 项检查 PASS（bundle schema/工件哈希/回执一致/快照可解析/问题可解析/验证指令/局限非空/依赖锁哈希/证据等级）→ exit 0。
- 念白：「这是别的产品没有的——把工作台导出成包，任何第三方离线复算，十项检查独立验证。」

## 8:30–9:20 桌面形态 + 运维（多表面一体）

- 画面：`cd desktop && npx tauri dev`（或直接运行已构建 exe）→ 桌面窗口打开同一工作台。
- 终端切回：`node dist/cli/main.js data info`（runs/库体积/工件真值）→ `curl http://127.0.0.1:3196/api/v1/health`。
- 念白：「Web、CLI、桌面三表面同一内核同一术语；health 报告真实 DB 与路由状态。」

## 9:20–10:00 诚实边界收尾（信任主张）

- 画面：README「当前三门」段 + 反证判官 0.143 的指标页（`eval/north-star.json` 相应条目）。
- 念白（逐字稿）：「我们不承诺完美：反证判官的语义命中率是 0.143，距离 0.7 目标有差距且已归因；官方百炼路由的 live 验证待凭证。每一项数字旁边是它的证据文件。FAR-Lab 卖的不是答案，是你可以亲自验证的科学决策过程。」
